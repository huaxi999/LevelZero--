# 第零关·像素乐园

**游戏无止境，创意不设限。**

游戏不只是消遣，更是另一个世界的入口。在这里，你可以是拯救王国的勇者、运筹帷幄的指挥官，也可以只是安静经营一座小岛的旅人。愿你在这里，找到属于自己的诗和远方。

## 测试示例

[16 个测试文件](tests/) 共 159 条用例，由 `node:test` 运行。大厅回归在 `node:vm` 中加载 `app.js` 和 `storage.js`，注入模拟的页面事件、内存版 `localStorage` 和云接口。测试从登录、退出和提交成绩等业务入口触发，通过手动释放 Promise 控制响应顺序，再检查发出的请求和实际写入的记录。

### 飞机大战的成绩补交

账号 A 打了 120 分，测试让提交接口抛出断网错误。切换到账号 B 后，断言接口调用次数没有增加，A 的 120 分仍在待补交队列。恢复网络并切回 A，检查请求携带原账号和昵称，提交成功后再检查对应的队列记录已移除。

另一条用例用一个手动完成的 Promise 挂住 100 分的提交，等 A 的 200 分和 B 的 50 分都进入待补交队列，再让旧请求返回成功。最后直接读队列，确认 A 的 200 分和 B 的 50 分都还在。

在仓库根目录运行这两条用例。

```bash
node --test --test-name-pattern='A offline scores stay|a late score acknowledgement' tests/site-shell.test.mjs
```

### 本地与云存档的一致性

- **宠物云存档的条件更新**　让两个保存请求携带相同的 `updatedAt` 和 `revision`，在模拟数据库中暂停其中一次更新。等第一个请求写入成功再放行第二个，断言第二个请求报告版本冲突，并读取保存记录，确认余额来自第一次写入。
- **巅峰对决的写入冲突与失败重试**　两个页面读到同一版存档。一个页面改名并保存后，另一个页面尝试用旧版本保存设置，断言旧写入被拒绝且新名字保留。另一个用例让 `localStorage` 抛出写入错误，检查存档内容和版本号没有变化，恢复写入后重试才推进版本号。

### 游戏逻辑与交互

- **爆炸弹结算**　交换主目标在敌机数组里的位置，覆盖溅射先移除其他敌机的情况。检查每个击杀只结算一次分数和掉落，仍有血量的敌机不被误删。
- **首页轮播**　用模拟计时器推进到自动切换前 1 毫秒，再按住推荐入口。越过切换点时检查该入口仍可操作，释放指针后验证轮播重新计时。

### 浏览器、真机与持续回归方案

**桌面浏览器回归 · pytest + Playwright**

用 fixture 启动本地站点，每条用例使用独立的浏览器上下文。桌面路径覆盖从大厅进入格斗之王再返回后的焦点，以及超级弹球按 Esc 暂停和继续。巅峰对决的存档测试在同一上下文打开两个标签页，检查第二个标签页收到写入占用提示，在关闭第一个标签页后能重新进入并读到已保存的角色。

**Android 真机回归 · Appium + UiAutomator2**

用 `adb reverse tcp:8000 tcp:8000` 让手机访问测试机上的站点，ChromeDriver 与手机上的 Chrome 版本匹配。真机用例从底栏进入猜拳，出拳后检查结算，再返回首页检查导航状态。用同样的方式打开勇闯魔王城，检查 iframe 里的首屏按钮可点，返回大厅后仍能点击底栏和游戏列表。

**持续回归 · Jenkins**

GitHub 推送触发回归。先用 Node.js 24 执行 `node --test`，通过后用同一提交启动站点并运行 pytest。真机用例按需交给连有 Android 设备的节点。浏览器用例失败时，Jenkins 收集 JUnit XML 和 Playwright trace，用来区分页面没打开、操作没完成和断言失败。

## 实现细节

深渊远征以 1/120 秒的固定步长更新战斗逻辑，画面由 Canvas 逐帧绘制。巅峰对决会预演出牌顺序，检查后续卡牌能不能接上，再逐张结算伤害和状态效果。

排行榜按账号保存待补交的成绩，提交成功后只移除对应记录。宠物云存档写入时会校验版本，避免覆盖其他设备刚保存的进度。

## 本地运行

游客可以直接试玩。登录后可以提交排行榜成绩、在留言板交流，宠物存档也会随账号同步。

使用 Node.js 24。在仓库根目录运行以下命令，然后打开 [http://127.0.0.1:8000/](http://127.0.0.1:8000/) 试玩。

```bash
node local-server.js
```

在仓库根目录运行 Node.js 回归用例。

```bash
node --test
```

## 游戏列表

- **街机飞机大战**　开战机躲弹幕、打首领，途中挑选强化模组，每局可以换个打法。
- **超级弹球**　移动挡板接球，靠反弹打碎砖块，接道具、攒连击。
- **猜拳擂台**　和电脑玩石头剪刀布，普通关赢一局就能过，遇到首领得多赢几次。
- **格斗之王**　选个角色上场，用拳脚和防守找机会，打出连招和必杀技。
- **格斗之王：深渊远征**　选剑士或格斗家，从主城接任务，进横版副本打怪、刷装备。
- **巅峰对决**　组一套卡牌去闯地下城，按顺序出牌，把击飞、浮空和终结技接成连段。
- **勇闯魔王城**　站内接入的爬塔 RPG，培养角色，逐层打怪闯关。
- **宠物王国**　领养一只电子宠物，给它喂食、洗澡、陪它玩，看它随时间长大。
